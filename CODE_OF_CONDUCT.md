# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1,
as its code of conduct. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

The short version: participate in a way that makes other people want to keep participating. Assume
good faith, disagree about the work rather than the person, and take correction gracefully. Harassment
of any kind is not tolerated, here or in any space where you are representing this project.

## Reporting

Report unacceptable behaviour privately to the maintainers via
[GitHub's private reporting](https://github.com/blove/ag-ui-chrome-extension/security/advisories/new)
— it is the private channel this repository has, and it reaches only the maintainers.

Reports are handled confidentially. Maintainers who violate this code are subject to it in the same
way as anyone else.

## A note on technical disagreement

Robust technical argument is welcome and expected. This codebase asks contributors to justify
decisions and records the reasoning in the code itself, which means review here is more pointed than
in many projects. That is about the work.

Pressing hard on a design is fine. Pressing on a person is not. If you are unsure which one you are
doing, you are probably close enough to the line to rephrase.
